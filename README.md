# Портфолио

Личный сайт-портфолио на React + Vite. Публикуется на GitHub Pages через GitHub Actions при каждом пуше в `main`.

## Запуск

```bash
npm install
npm run dev
```

## Содержимое

Весь текст, проекты и ссылки лежат в `src/data.js`. Менять сайт можно, не трогая компоненты.

## Публикация

1. Создайте репозиторий на GitHub и запушьте код в ветку `main`.
2. В настройках репозитория откройте Settings, Pages и выберите Source: GitHub Actions.
3. После первого запуска workflow сайт появится по адресу `https://<ник>.github.io/<репозиторий>/`.
